# Pencarian Buku: Linear Search vs Binary Search

Tugas 1 Analisis Algoritma. Membandingkan Linear Search dan Binary Search pada dataset buku.

Dataset (Kaggle): https://www.kaggle.com/datasets/mihikaajayjadhav/books-dataset-15k-books-across-100-categories

## File
- kelas.py : kelas input dan output, serta pembacaan dataset
- main.py : Linear Search, Binary Search, demo, dan pengujian
- hasil_pengujian.csv : hasil pengujian
- grafik_pengujian.png : grafik perbandingan

## Cara menjalankan
1. Unduh dataset dari link di atas, ambil file google_books_dataset.csv
2. Taruh file itu satu folder dengan kelas.py dan main.py
3. Jalankan: python main.py
